# Portafolio Web Profesional - David Gil López

¡Bienvenido a mi portafolio! Una aplicación web responsiva diseñada para presentar mi perfil como desarrollador web, mis proyectos destacados y mis habilidades técnicas en el ecosistema Frontend y Backend.

## Características principales
***Diseño Responsivo:** Adaptado a cualquier pantalla usando el sistema de rejillas de Bootstrap 5.
***Navegación Fluida:** Enlaces ancla optimizados con desplazamiento suave (*smooth scroll*).
***Interactividad:** Menú colapsable en móviles, efectos visuales dinámicos y contador de caracteres nativo en el formulario de contacto.
* **Descarga de CV:** Botón directo optimizado para la descarga de mi currículum en formato PDF.

## Tecnologías utilizadas
***Maquetación y Estilos:** HTML5, CSS3 personalizado y **Bootstrap v5.3.8**.
***Tipografías e Iconos:** Google Fonts (*Playfair Display*, *Rubik Doodle Shadow*) y Bootstrap Icons.
***Habilidades expuestas:** * Frontend: HTML5, CSS3, JavaScript, Bootstrap 5.
  * Backend: Python, Java, PHP, SQL.
